## 三、产品介绍

本产品是一款跨语言法律观点对比助手。用户用中文、英文或俄文提出一个法律问题，产品通过知乎官方 API 检索知乎站内的相关问题与回答，把同一问题下的多条回答摘要并列呈现，再由知乎直答归纳出观点对比（共识与分歧），并用提问的语言呈现结果。每一个结论都附带溯源链接，可一键回到知乎原文核对。

产品的数据来自知乎官方 API，不做任何爬虫抓取。官方接口返回的是回答摘要而非全文，因此产品形态是“摘要 + 链接溯源”：摘要用于对比与归纳，全文通过链接回到知乎原文阅读。这一形态同时保证了数据的真实性与来源的可核查性。

技术实现为前端 + Node 后端，部署在 Cloudflare Workers 免费层。知乎账号登录（OAuth）是后接的可选模块，不在本次提交的版本内。自有法律文本上传后做检索增强（知识库 RAG）是第二阶段的扩展功能，本次提交版本只保留接口占位。

## 四、目标用户

- 法律研究者与法学生：写论文、做研究时需要快速了解某一法律问题的多方观点，而不是只看到单一高赞答案。
- 跨境法律从业者：律师、法务与合规人员，需要了解中国法律实务问题的中文讨论，但提问与阅读可用英文或俄文进行。
- 需要跨语言查询知乎法律问答的人：中文不够熟练，但需要直接使用知乎站内真实问答内容的用户。

## 五、产品价值

- **降低跨语言门槛**：用自己的语言提问，就能查询与使用中文法律问答内容，无需先翻译问题、再翻译答案。
- **呈现多方观点而非单一答案**：同一问题下的多条回答摘要并列展示，配合共识与分歧归纳，帮助用户看到争议所在，而不是只接受一种说法。
- **每条结论都可溯源**：所有结论附带知乎原文链接，用户可随时点回原文核对，避免把归纳当成原文。
- **基于官方接口，数据真实**：内容来自知乎官方 API 的实时检索结果，不是离线语料或模型凭空生成，答案有明确出处。

## 六、创新亮点

- **观点对比结构化**：不是返回一条综合答案，而是把多方观点整理为共识与分歧两类，每类结论对应具体的回答来源，便于判断争议焦点。
- **三语提问、三语呈现**：提问与结果呈现均支持中文、英文、俄文，跨语言的法律知识查询一次完成。
- **摘要 + 溯源的产品形态**：在官方接口只返回摘要的前提下，用摘要做对比、用链接做溯源，把接口限制转化为可核查的产品设计。
- **额度感知与优雅降级**：调用前查询官方额度，额度不足时自动降级并明确标注，避免无声失败；查询结果按小时缓存，减少重复调用。

## 七、功能介绍

1. **三语提问**：输入框支持中文、英文、俄文提问，可一键切换界面语言。
2. **知乎搜索**：调用知乎官方搜索接口，返回相关问题与回答的标题、摘要、作者、赞同数、评论数与链接（单次最多 10 条）。
3. **多回答摘要并列**：对选中的问题，拉取该问题下的多条回答摘要并列展示，支持翻页。
4. **观点对比归纳**：调用知乎直答，按提问语言生成结构化对比，包括总览、共识与分歧，可选快速、深度思考、智能思考三档。
5. **溯源链接**：每条共识与分歧结论均附带知乎原文链接，点击回到知乎核对。
6. **模式与额度显示**：页面顶部显示当前模式（真实数据 / 模拟模式）与各接口剩余额度，状态透明。
